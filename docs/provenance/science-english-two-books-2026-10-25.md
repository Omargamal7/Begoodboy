# English Science — two-book study pack

Nine chapter HTML files and 28 separate lesson HTML files combine the English textbook and the performance/assessment booklet. The chapter files group the separate lessons behind a selector; both use Explanation, Homework, Exercises & models, and Sources tabs. Original diagrams and questions are embedded; answers and completion notes save per lesson on the current browser. Export answers from Sources.

Textbook PDF: 110 pages, 2026–2027 edition (earlier website metadata said 109). Source: https://drive.google.com/file/d/12XSa7KQlC-BIsLpm82x1XrCFtpUYAwWX/view

Assessment PDF: 62 scanned PDF pages. Source: https://drive.google.com/file/d/1OjoipmjinEWTSUsR5TX6L2kpurfH0j95/view

Assessment printed page numbering is PDF page + 1 after the cover. The supplied assignment says printed pages 18, 19, 22, 23, 27, Homework Performance only. In this scan page 27 is germination; Sunlight and Growth starts on printed page 28 and its homework is printed page 29. This discrepancy is displayed; no extra homework is declared assigned.

`packs/gamal/science/english-term1/source-map.json` lists each lesson's source pages. Shared transition pages intentionally appear in adjacent lessons; users must follow the printed lesson heading and Homework Performance section. Original pages are authoritative. OCR text may misorder columns and is offered only as searchable support. Images preserve diagrams and tables. Related weekly/monthly models sometimes cover earlier chapters; they remain intact and are not falsely labelled single-lesson tests.

The automatic checks are newly generated source-sentence cloze recall, not official test questions or an official answer key. The complete source sentence is shown before each check. Official written homework and models use open responses with parent review, not invented automatic grading. No school answer key was supplied. Read-aloud uses device speech; source images themselves are not spoken, so use searchable text for reading assistance. No generated audio is bundled.

All textbook lesson pages, chapter enrichment, assessment pages 2–61 and monthly model continuations are covered. Textbook scientific-method/tool pages 104–107 are in science-skills.html. Credits/front matter and blank back covers remain in the full PDF archive. Each HTML embeds images and runs offline. Local file browser storage support varies; export answers regularly.
