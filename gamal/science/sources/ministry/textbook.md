# English Science textbook and two-book learning collection

[Open the chapter and lesson menu](../../../../packs/gamal/science/english-term1/index.html).

The original English textbook is archived unchanged in `textbook-parts/`. Run `python3 tools/source/restore-originals.py` from the repository root to reconstruct `Science_Textbook_Grade5_Term1_2026-2027_English.pdf` here. The 110-page PDF is the Ministry's 2026–2027 first-term edition. [Open PDF online](https://drive.google.com/file/d/12XSa7KQlC-BIsLpm82x1XrCFtpUYAwWX/view).

Nine chapter HTML files and 28 separate lesson HTML files combine explanation pages, corresponding Homework Performance pages, textbook exercises and related assessment models. Source images are embedded; responses save locally. No official homework answer key was supplied. [Homework scope and edition discrepancy](homework-scope.md).
