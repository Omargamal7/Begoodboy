# Begoodboy lesson sheets

Interactive ICT lesson sheets for two brothers, built from their school booklets
(first term 2025-2026). Each sheet is one HTML page that runs in a browser on an
Android tablet or a Linux laptop. Nothing is printed and nothing is installed.

- `index.html` lists the sheets.
- `assets/sheet.js` and `assets/sheet.css` are the shared sheet engine.
- Each lesson is one HTML file that only holds that lesson's content.

Every fact and question in a lesson file comes from the school booklet.
The plans behind the design are in the two Claude Docs plans for Murad and Jimmy.
